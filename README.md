# Guard Hero Browser

> **The browser that fights back.**

Guard Hero Browser is a privacy-first Chromium fork built on [ungoogled-chromium](https://github.com/ungoogled-software/ungoogled-chromium). It ships the **EagleEye** native blocking engine — a C++ Bloom-filter + hash-map tracker blocker that handles 93,000+ domains with sub-millisecond lookup — along with canvas fingerprint noise, WebRTC leak protection, and a full React browser UI.

---

## Architecture

Guard Hero is assembled from four layers applied on top of the base Chromium source tree:

```
┌──────────────────────────────────────────────────────────────────┐
│                      Guard Hero Browser                          │
│                                                                  │
│   browser-ui/          eagleeye-native/        patches/          │
│   ┌─────────────┐      ┌──────────────┐       ┌─────────────┐   │
│   │ newtab/     │      │ blocker/     │       │ core/       │   │
│   │ popup/      │      │   domain_    │       │ privacy/    │   │
│   │ settings/   │      │   matcher    │       │ eagleeye/   │   │
│   │ (React/TSX) │      │   url_       │       │ ui/         │   │
│   └──────┬──────┘      │   analyzer   │       │ ai/         │   │
│          │ chrome.     │   cname_     │       └─────────────┘   │
│          │ guardhero.* │   resolver   │                          │
│          └─────────────┴──────────────┘                          │
│                          │                                       │
│               ┌──────────▼──────────────────────────────┐        │
│               │     Chromium Browser layer               │        │
│               │  chrome/browser/  net/  blink/renderer/ │        │
│               └─────────────────────────────────────────┘        │
│                          │                                       │
│               ┌──────────▼──────────────────────────────┐        │
│               │   ungoogled-chromium patches             │        │
│               │   (degoogle, privacy fixes)              │        │
│               └─────────────────────────────────────────┘        │
│                          │                                       │
│               ┌──────────▼──────────────────────────────┐        │
│               │   Base Chromium source (via gclient)     │        │
│               └─────────────────────────────────────────┘        │
└──────────────────────────────────────────────────────────────────┘
```

### Patch layer order

```
Base Chromium
    │
    ▼  (1) ungoogled-chromium patches   — removes Google service hooks
    ▼  (2) patches/core/               — branding, guardhero:// URL scheme, default prefs
    ▼  (3) patches/privacy/            — canvas noise, battery API block, Safe Browsing off
    ▼  (4) patches/eagleeye/           — registers EagleEye in network service, toolbar button
    ▼  (5) patches/ui/                 — NTP override, settings page additions
    ▼  (6) patches/ai/                 — AI side panel, tab indexer, reader bridge (v1.3+)
    │
    ▼
Guard Hero Browser
```

## Quick-start build

### First-time setup (recommended)

The `setup.sh` script handles everything automatically: depot_tools, Chromium source sync, Ungoogled Chromium patches, Guard Hero patches, GN configuration, and the build itself.

```bash
./setup.sh                  # full setup — runs everything end-to-end (~3 hours)
./setup.sh --check          # check prerequisites only, then exit
./setup.sh --sync-only      # only sync Chromium source (skip build)
./setup.sh --patch-only     # only apply patches (skip sync + build)
./setup.sh --build-only     # only build (assumes sync + patches already done)
```

**Prerequisites** (checked automatically by `setup.sh`):

- macOS 13+ or Ubuntu 22.04+
- Xcode 15+ (macOS) or `build-essential` (Linux)
- Python 3.9+, Node.js 18+, Git 2.30+
- 80 GB free disk space (source ~30 GB, build output ~40 GB)
- 16 GB RAM recommended

### Manual steps (advanced)

If you prefer to run each step individually:

```bash
# 1. Install depot_tools
git clone https://chromium.googlesource.com/chromium/tools/depot_tools.git .depot_tools
export PATH="$PWD/.depot_tools:$PATH"

# 2. Fetch Chromium source (first run only — takes 60–120 min, ~30 GB)
gclient sync --with_branch_heads --with_tags --no-history --jobs=8

# 3. Apply Ungoogled Chromium patches (privacy base layer)
git clone https://github.com/ungoogled-software/ungoogled-chromium.git .ungoogled-chromium
python3 .ungoogled-chromium/utils/patches.py apply src/ .ungoogled-chromium/patches/

# 4. Apply Guard Hero patches
python3 build/apply_gh_patches.py --src-dir src/

# 5. Build browser-ui React assets
cd browser-ui && npm ci && npm run build && cd ..

# 6. Configure with GN
cd src/
gn gen out/Release  # args.gn is generated by setup.sh, or create manually

# 7. Build (~60–120 min)
autoninja -C out/Release chrome

# 8. Package
build/macos/make_dmg.sh           # → dist/macos/GuardHeroBrowser.dmg
build/linux/make_deb.sh           # → dist/linux/guardhero-browser_*.deb
build/windows/make_installer.ps1  # → dist/windows/GuardHeroBrowser-Setup-x64.exe
```

## Local development

You don't need a full Chromium build to work on the UI or the C++ blocking engine. The dev workflow has three tiers:

| Tier | Command | What it does |
|------|---------|--------------|
| 1 | `./dev.sh` | React UI dev server with hot reload |
| 2 | `./dev.sh test` | C++ unit tests (gtest) |
| 3 | `./dev.sh e2e` | Playwright E2E tests against the live UI |

### Tier 1 — React UI dev server

**Requirements:** Node 20+

```bash
./dev.sh
```

Starts Vite at `http://localhost:5173` and opens the Dev Launcher. All `chrome.guardhero.*` APIs are mocked — no browser binary needed. Mock events fire every 2 seconds so the Request Inspector streams live data immediately.

Panels available:

```
http://localhost:5173/index.html          ← Dev Launcher
http://localhost:5173/newtab/index.html   ← New Tab Page
http://localhost:5173/popup/index.html    ← Toolbar Popup
http://localhost:5173/settings/index.html ← Settings
http://localhost:5173/devtools/index.html ← DevMode Panel
```

You can also start individual panels directly:

```bash
cd browser-ui
npm run dev:newtab    # opens New Tab Page
npm run dev:popup     # opens Toolbar Popup
npm run dev:settings  # opens Settings
npm run dev:devtools  # opens DevMode Panel
```

### Tier 2 — C++ unit tests

**Requirements:** macOS: `brew install googletest` · Linux: `sudo apt install libgtest-dev cmake`

```bash
./dev.sh test           # run all C++ suites
./dev.sh test domain    # domain_matcher tests only
./dev.sh test url       # url_analyzer tests only
```

Compiles and runs gtest suites for the EagleEye blocking engine without needing a full Chromium build. Expected output: 46 tests, 0 failures (28 url_analyzer + 18 domain_matcher).

### Tier 3 — Playwright E2E tests

**Requirements:** Node 20+, Tier 1 running in a separate terminal

First-time setup:

```bash
cd browser-ui
npm install
npx playwright install chromium   # ~120 MB, one-time download
```

Run the tests:

```bash
# Terminal 1 — keep the dev server running
./dev.sh

# Terminal 2 — run E2E suite
./dev.sh e2e
```

Open the interactive Playwright UI (recommended for debugging):

```bash
./dev.sh e2e:ui
```

The E2E suite covers all five panels across Chromium, Firefox, and WebKit. HTML reports are written to `browser-ui/playwright-report/` on failure.

### Run everything

```bash
./dev.sh all    # Tier 2 (C++ tests) → Tier 1 (UI dev server)
```

## Contributing

### Writing patches

1. Make your changes directly in the Chromium source tree (`src/`).
2. Stage changes: `git add -p`
3. Generate a patch:
   ```bash
   git diff --cached > patches/<category>/NNN-description-of-change.patch
   ```
4. Follow the naming convention: `NNN-short-kebab-description.patch` where `NNN` is the next sequential number in that category.

**Patch naming conventions:**

| Range   | Category    | Purpose                                   |
|---------|-------------|-------------------------------------------|
| 001–009 | core/       | Branding, URL schemes, default settings   |
| 010–019 | eagleeye/   | EagleEye integration, toolbar             |
| 020–029 | privacy/    | Fingerprint noise, API blocking           |
| 030–039 | ui/         | NTP, settings, popup                      |
| 040–049 | ai/         | AI features                               |

### Rebase procedure

When Chromium releases a new stable tag:

```bash
# 1. Check if a new version is available
python3 build/check_upstream.py

# 2. Rebase all patches onto the new tag
python3 build/rebase.py --target-tag=<chromium-tag>

# 3. Resolve any conflicts (the script will pause and report)
# 4. Verify the build
python3 build/apply_gh_patches.py --dry-run

# 5. Full build verification
autoninja -C out/Release chrome
```

See [docs/REBASING.md](docs/REBASING.md) for the full procedure.

### Code style

- C++ follows the [Chromium C++ style guide](https://chromium.googlesource.com/chromium/src/+/main/styleguide/c++/c++.md).
- TypeScript/React follows the ESLint config in `browser-ui/`.
- All new C++ code must have unit tests in `tests/unit/`.
- Run the privacy audit before submitting: `python3 tests/privacy_audit.py`
